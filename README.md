# VisualExtension
VisualExtension é uma extensão visual criada para que usuários com Daltonismo possam ter uma melhor experiência ao navegar pela Web. A extensão foi publicada e segue todas as normas e diretrizes de privacidade da plataforma Chrome Web Store

# Acesse o Projeto
Acesse e instale a extensão através do link a seguir: https://chromewebstore.google.com/detail/visualextension/gbfjhbiepcngebolhkicmlmjcoiminbi?hl=pt-BR&utm_source=ext_sidebar
